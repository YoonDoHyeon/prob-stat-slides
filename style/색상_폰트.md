# 색상과 폰트 (01회차 샘플 기준)

## 색상
- 주 색상: #1F3A5F 남색 (제목, 표 머리글, 그래프 주선)
- 강조 색상: #E07A2E 주황 (핵심 수치, 강조 영역)
- 보조 색상: #8FB8DE 하늘색 (그래프 보조)
- 박스 배경: #EEF3F8 연한 회청색
- 본문 글자: #222222 / 보조 글자: #888888

## 폰트
- 전체: Apple SD Gothic Neo (제목 30pt 굵게, 본문 19~22pt)
- 그래프 속 수식: STIX (이탤릭 수식체)
